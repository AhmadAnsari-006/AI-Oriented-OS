# Setup & Run (Windows)

1. Create a virtual environment and install dependencies:

```
setup_env.bat
```

2. Run Chat-Bot (v1):

```
run_v1.bat
```

3. Run Chat-Bot (v2):

```
run_v2.bat
```

Notes:
- The project expects Python 3.8+ on PATH.
- Edit `requirements.txt` to pin or add packages as needed.
